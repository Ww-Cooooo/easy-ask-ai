# Easy Ask AI 通用宿主安装与接入

宿主、版本、配置路径、规则载体和加载顺序按当前运行实例核实。本指南给套件使用者和安装 Agent 作入口；详细步骤也分别随两项 Skill 提供，因此单独复制任意一项仍可独立安装、接入、复查和撤销：[Prompt Ready](../skills/prompt-ready/references/host-integration.md) · [Get Clear](../skills/get-clear/references/host-integration.md)。

## 给安装 Agent 的启动指令

在能读取用户本机文件的 Agent 会话中，把尖括号换成实际信息后发送。即使 Skill 尚未安装或未被发现，该指令也从用户提供的路径开始，不依赖未加载的 Skill 自行启动：

```text
我提供的 Easy Ask AI 完整套件或 Skill 目录位于「<本机实际路径>」。请安装「<prompt-ready / get-clear / 两者>」到「<当前项目级 / 用户级>」范围；持久规则选择「<接入当前项目 / 接入用户级 / 只安装不接入>」。先读取目录中的 README.md 和所选 Skill 的 SKILL.md、references/host-integration.md、assets/agents-snippet.md、assets/host-setup.template.md；必要文件逐一读取；输出截断时补读缺失部分，不能只凭执行过读取命令就当作已完整获得说明。如果提供完整套件根目录，还读取根 README.md 与 docs/host-integration.md。根据当前宿主实际提供的技能/配置/帮助/状态工具、可读取的有效配置，以及与已核实版本相符的官方文档或实现，查清宿主和版本、工作区、安装与发现方式、持久规则载体、规则作用范围和覆盖关系、加载/刷新/新会话要求。先做只读核验；我已明确授权的范围直接完成，不重复询问。若安装或接入范围尚未明确，只在完成只读核验后询问会改变结果的范围选择。保留配置和本地定制，写入前备份；只安装表示不改持久规则。没有可靠证据时不要猜写。完成后分开报告安装、宿主发现、规则写入、宿主加载、模型读取入口、正常输入行为和仍待验证的状态，并说明如何撤销。
```

## 通用原则

- 从当前会话实际提供的配置、Skill 列表、帮助、状态或文件读取工具开始；再查看这些工具指向的配置。仍有事实缺口时，使用与已核实版本匹配的官方文档或实现。未知宿主同样调查，不假设统一的自述 API，不凭模型自报、文件存在或旧记录猜路径。
- Skill 安装与持久规则接入是分开的操作。只安装不改规则；普通或显式业务调用也不授权新增项目级/用户级规则。范围已在可信当前对话中明确时可沿用，没说明范围时只问这一项决定性选择。
- 写规则前确认真实活动载体、格式、覆盖和加载方式。用宿主原生设置工具或按文件原生格式编辑；Markdown 不能直接塞进 JSON/YAML。备份后只拥有可识别的独立区段或原生条目，保留其他内容和本地定制。
- 没有持久规则机制时保留显式调用或逐任务提供入口，不宣称已接入。只读环境或只有 UI 而当前没有可用操作能力时，说明已观察状态与用户可执行的准确下一步。
- 分开报告文件已安装、宿主已发现、规则已写入、宿主已加载、模型在动作前读取入口、正常输入下隐式入口及行为通过、用户接受。宿主 `loaded` 诊断不证明模型读过 Skill；显式调用不能代替隐式测试；没有新会话或读取记录时写明待验证。

## 记录、更新与撤销

接入指南要求先读各 Skill 随包的 `assets/host-setup.template.md`。首次创建须保留模板起止标记，填写实时 Host、Scope、有效载体和证据状态；保存后回读核对标记与当前值。默认文件为 `.easy-ask-ai-host-setup.md`，遇到已有无标记文件须保留并另存为符合 `.easy-ask-ai-host-setup*.md` 的自有文件。首次轻量检查仅在实际 Skill 目录发现该模式文件，按 Skill 身份标记以及当前 Host、Scope、有效载体匹配，不按文件名、修改时间、版本号或最新日期选取。更新/撤销后刷新当前自有记录、标记相关旧证据失效并保留必要历史。完整接入时同时保存安装包文件清单及内容指纹（如逐文件 SHA-256），以及规则片段与活动自有区段/原生条目的指纹或可比较副本；不能只凭 Skill 版本号认定内容没变。日常轻量核验不做全盘哈希；缺少匹配记录、路径或权限时把状态标为未知/未保存，不延迟明确业务。文件、规则或宿主状态变化时按影响范围重新核验，旧记录不延续权限或自动证明当前加载。

撤销只删除能确认属于 Easy Ask AI 的区段或原生条目，保留 Skill 安装及其他规则。备份用于核对和恢复受影响部分；其他规则后来变化时不能用整份旧备份覆盖当前配置。卸载 Skill 是单独动作，也只删除可确认属于该包的文件并保留本地定制。

Codex、DeepSeek Harness、Claude Code、WorkBuddy 等名称只在其具体历史环境提供调查线索，不构成允许名单、路径表或当前兼容证明。当前有效状态始终以该实例和版本的证据为准。
