# 在当前回合提供宿主路由

本页供已经获准的宿主持久规则接入、更新及“开场读过，后续没有落实”的排查使用。普通返修不重新安装。它补充[宿主接入](host-integration.md)，不代替完整技能、访谈或用户对本次产出的决定。

## 先查真实接口，不把提醒当强制执行

区分：技能是否可发现、规则是否进入了首次请求、后续回合是否仍获得相应规则、实际动作是否符合当前阶段。规则可见却仍猜整版、只说计划或跳过报告时，不再以重装或重复写“必须”宣称修好。

接入调查应确认规则实际进入模型时的角色、顺序与刷新时点，而非只看文件名。有的宿主只在开场加入用户级上下文，内容不变就不再注入；有的支持原生持久指令段或每次用户提交时的同步命令接口。查询当前版本的配置、接口说明或实现，选择它确实支持、与已授权作用范围一致的载体；不得靠字符串中的 `system` 标签伪造消息角色，也不改宿主原有身份、安全指令或模型路由。

若宿主支持每回合或每步提供用户可配置的持久指令，可以在其中仅加入本 Skill 的自有路由段。若它支持同步提交事件返回附加上下文，可使用下面的渲染器。不要把通用启动文件、一个产品的钩子名或配置路径硬套到其他宿主；没有这些能力时保留已验证的原生接入，分别记录加载与行为的限制，不编造接口。

提醒提高当前回合的规则可用性，不是授权分类器、写入拦截器或行为保证。它不替用户认可报告，也不把“别问我专业的”变成制作委托。真正的工具拦截需要宿主另有实现，本包不借提醒虚称已经阻止所有错误写入。

同一产品的桌面、命令行或不同 profile 可能使用不同的配置链。核实实际入口和继承关系；桥接了模型与思考档位，不证明桥接了规则。多个入口需要接入时，各自保留原字段和 persona，再合并同一自有路由；不把一套入口的原配置覆盖到另一套，也不把测试临时参数中的提醒当作已部署规则。按每个载体真实的启动或刷新要求验证；新进程加载不证明已经运行的桌面进程已热重载。

## 复用随包规则，不维护第二份业务方法

[`scripts/emit_routing.py`](../scripts/emit_routing.py) 使用 Python 3.10+，只依赖标准库。它从选定安装包的 `assets/agents-snippet.md` 提取自有段，绑定该包的实际 `SKILL.md`，不维护另一份访谈规则。默认包位置由脚本所在目录确定；安装配置建议显式传入已核实的选定目录。

已核实的解释器和路径替换占位符后，使用宿主的参数数组执行方式；该能力不存在时，按该宿主真实 shell 的引号规则处理，不把 JSON 转义当 shell 转义。Windows 上若确需 PowerShell，使用 `pwsh`。

```text
<Python 可执行文件> -X utf8 <安装目录>/scripts/emit_routing.py --format text --skill-dir <安装目录>
```

`text` 输出纯文本，适合宿主原生指令段或其他已经核实的适配器。写入配置时保留原字段、既有指令、注释和其他规则，仅更新能够识别的自有段；不要把它覆盖为整份 persona 或配置。若宿主有模板插值，先检查其转义要求，不能把占位符或模板控制符原样写入。

`claude-submit` 只用于已核实支持该协议的 `UserPromptSubmit` 同步命令事件：stdin 是宿主事件 JSON，事件名须匹配；stdout 是 `hookSpecificOutput.hookEventName` 与 `additionalContext`。这不是其他宿主的通用 JSON 协议。当前版本支持直接执行参数数组时，配置形状为：

```json
{
  "type": "command",
  "command": "<已核实的 Python 可执行文件>",
  "args": ["-X", "utf8", "<安装目录>/scripts/emit_routing.py", "--format", "claude-submit", "--skill-dir", "<安装目录>"],
  "timeout": 5
}
```

这只是单个 handler 的形状，不能覆盖为整个宿主设置。安装者须查清当前事件容器、禁用/受管限制、执行形式与优先级；不能假设所有版本都接受 `args`。不启用异步或只运行一次，否则不是当前回合的同步路由。渲染器仅验证事件名，不解释、保存或回显用户提示，不读取聊天记录、凭据或宿主配置，不联网、不写文件。缺包、缺标记或协议错误时返回非零并不给出路由；安装核验必须观察这类失败，不当作成功提醒。

## 合并、更新和撤销

先备份将改变的内容并核对当前摘要；有并发修改就重新读取。原生文本段沿用 `easy-ask-ai:get-clear` 标记。命令接口不接受自造 ID 字段时，在本地自有接入记录中保存 handler 的类型、实际脚本/解释器路径、参数及摘要，用它精确识别自身条目。只能更新或撤销该条目；零个、多个或内容已被其他人改动时先保留并报告，不能删除整个事件或其他 hook。

回读时核对自身项、外部字节/原设置保留和实际有效配置。完整包更新后，重新生成受影响的原生文本段或核对渲染器读取的新规则；同步刷新接入记录的包清单、规则/handler 指纹及证据状态。撤销提醒不等于卸载 Skill，也不能声称旧会话已清除上下文。

## 验证当前回合和完整行为

新会话使用普通业务输入，不点名 Skill，不在测试输入追加维护者提示。先观察真实事件/配置加载，再检查提醒是否进入本次模型输入及其位置；启动成功、stdout 存在或进程退出 0 都不独立证明它到了模型。

继续走多轮：征求意见、拒绝专业判断、仍说不清、新的明确制作委托、产出被整体否定、偏好补齐、报告补充、明确认可后的实际保存。分别看是否实际发问、是否误做完整新版、是否交报告并在补充后重呈、是否认可后才制作并保留原件。读取与行为分开记录，失败保留并修正相应层，不用一次加载证明后续全部遵从。
