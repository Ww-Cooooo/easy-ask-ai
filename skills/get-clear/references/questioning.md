# 怎样把问题问到点上

用户表达含糊时，不是让其填完整规格。结合当前作品，找出回答后确实会改变结果的一处体验差别。

## 逐轮核对实际问句

本页是 Get Clear 对下一问的唯一完整发送前检查。每次准备把问题发给用户或问答工具前，先写出将实际发送的句子和全部选项，再逐项检查、改正；收到回答后重新判断当前阶段，对下一问重复此检查。工具返回答案与普通消息适用同一流程。完整改向的复述确认另按[访谈第 4 节](interview.md#4-问清楚的判据与确认)校对。

先检查本轮准备发送的是**辨认问题，还是批准请求**。用户尚未选定替代效果时，让其检查一整套猜测设计、确认用途或纠正报告，不等于问到那处效果差别；保留未知，改为基于当前作品的一问。用户拒绝专业判断时降低问法门槛，不用整套方案报告代替问题。方向已明确时仍正常进入报告核对，不重复问已解决的偏好。

1. **核对作品与事实。** 技能读完后，单独取回问题所依据的当前作品、简报和有效决定中的原句，不用自己的摘要代替；刚才已单独读取且仍有效的依据可复用。问题及每个选项都要有实际观察或原句支撑，并保留对象、时间/阶段、条件、范围、数值、否定及约束强度：必须、建议、可选、禁止不能混为一谈。材料冲突时先定位两处原句；能自行查明的事实不要让用户重答。没有依据的说法删去或明确为待确认，不能包装成原有要求。
2. **只辨认一处可感知的差别。** 问句要指向实际作品或已确认的用途，一轮只问一个主要决定。选项保留相同事实与功能，只改变本次要辨认的体验；不同回答应导致不同的后续选择。问用户更接近哪种结果，不让其诊断原因、挑缺点、提供专业术语或选择谁找参考。选项中性，可回答“都不是”“都有一点”或“说不清”，不推荐用户喜欢哪项。
3. **限制答案的含义。** 先检查回答里的关键用词、指代、程度和前提是否已经明确；表面上回答了题目，不代表其中的歧义已消除。仍可能导向不同改法时，按下节辨别含义。用户的回答只更新本题所测的偏好或约束，不证明你猜的原因，也不自动确定整体改向、授权修改或代表用户接受方案。连同每个选项后附的下一步动作一起检查；局部回答不预先绑定为整版制作、报告认可或委托，不能写成“还行，我就把整张做完”。仍有未决项则继续辨认，分歧已清则交报告核对。没有回答、仍说不满意或说不清时，保留未决项；新增线索只解决它实际涉及的维度。
4. **让用户看得懂比较对象。** 优先用已检查的作品或参考作锚点。文字题用事实一致、质量相近且只变一个维度的短例；视觉或声音差别需要实际可见、可听的材料。用户没有自带参考不是障碍：由 Agent 查找、筛选并展示可访问的现成材料，不问“谁来找”或是否要继续澄清。现成材料仍不能显示本题差别时，可在当前已授权任务内做一份临时局部对照，须符合下文规模线；不改业务原件、不把它当新方案或已接受设计，也不另行索要制作许可。用户要求停止、看备选稿或委托决定时，按[访谈确认规则](interview.md#4-问清楚的判据与确认)的判据处理，征求意见不适用执行例外。

若实际措辞或任何选项没通过检查，先修订再发送，不靠事后附注纠正。工作记录只留足够的原句、已知偏好和未决项，不要求用户审阅过程表。反复否定、全选缺点或无法描述时，另读[多轮反馈恢复方法](repeated-feedback.md)；它决定如何更换辨认方式，问句本身仍按本页核对。

### 把候选问题落到材料上

先在工作记录标明本问的**实际比较对象及位置、只辨认哪处差别、每个选项在何处可见**；不用把这三项变成给用户的表格。若选项只能靠想象一套新作品才能回答，就还没有形成可发送的问题。先用已检查的原作/参考，缺少时补足当前一问所需的局部对照，再问。

例如，三张虚构菜单已被否定，问“做成电影海报、精致杂志还是手写小店”是在让用户选三套未见过的新方向；问现有菜单中实际可见的“价格紧跟菜名、统一靠右、各自放进框里”才在辨认同一处关系。使用真实任务里的表现，不把这个例子的对象或答案照搬过去。一组作品全否时，先按恢复页取得组级锚点；用户已明确没有相对可取项时，不重复索要认可，转到这种具体辨认。

不在问句末尾附“懒得选就说你定”“不想回答就授权我做”等绕开澄清的建议，也不将委托列为偏好选项。用户自己明确提出的有效委托仍照常执行，真正暂停则停止；二者不是 Agent 为结束当前难题而引导的答案。

### 拒绝专业判断时，先交可回答的一问

用户不愿承担专业判断，而当前这一处还没有给过低门槛选项时，本轮直接按以下顺序构造并发出回复：**指出已观察作品中的一处客观表现 → 就同一处问普通的观看或使用感受 → 给三个具体可辨认的答案及“都不是／说不清” → 等待答案。** 用户只需报告自己看到、听到或用到的感受，专业改法仍由 Agent 负责。先用现成作品完成这一问；此时不是选择或制作辅助材料的回合。上一轮问哪张最不差，不等于已为本轮这处区别提供了三个可辨认的答案。

可据真实材料写成：“先只看[作品中的具体位置]，这里[一句客观观察]。你看／用到这里时，更接近[反应甲]、[反应乙]还是[反应丙]？也可以都不是或说不清。”三个答案只区分同一处体验，不是三套专业设计方案。先查实位置和表现，再换成普通人的说法；需要给意见时，只用一句解释这条观察与本问的关系，不先写完整改向宣言。问题的答案应能辨认用户对当前作品的感受；若它只是在补齐自己新设想的背景事实，尚未回答用户为何不满意，换回当前作品的一处感受问题。确有缺失的必要事实仍按访谈流程查证或单独问，不借它宣布整套效果已经确定。

这题得到线索就继续原访谈；对这处仍拒答，才按[访谈的拒答分支](interview.md#征求意见委托与拒答)选择受限局部假设，并实际发出本轮问题。有效新委托、限定看稿、明确小改、报告认可及真正暂停仍走各自分支，不被本构造拦住。

默认先直接用现有作品，不为展示专业能力而新制材料。比如指向原作中确有的一块图形或一句话，让用户暂时遮住/跳过它，只辨认“更舒服、没区别、反而缺东西”；这比让用户想象整套新风格更容易回答，也不要求其决定专业做法。文字、画面或行为用实际任务的对象，不照搬例子。确实需要新局部材料时，达到能看出本问差别就实际发问，不进入美化与多版本试制循环。

### 局部对照的规模线

为当前一问新制的材料，合计限**单张局部图或一个局部文字/声音/动作片段、单一维度、只回答当前一问**；其余维度沿用，不同时改两个以上维度，不修改原件，不作交付。可与现有原作对比，但不能连续累积局部稿，拼成未经确认的整体方案。

范围按相对原作的实际变化计算，不按“构图”“气质”等概括计为一个维度：同时改变主图的容器、标题位置和底色，仍是三项变化；只画半页或省去信息区不会使它变成单维。先列明本次改变的一项，其他可见属性沿用原作；不能做到时，使用原作加短例辨认，不另造多维示意。

实际制作时从原作复制或提取当前局部，只替换本问所测的那一项，再回读差异；不要在空白画布重新设计一个“更好”的局部。比如只辨认轮廓，就沿用原有颜色、位置、光线和纹理，不顺带增加雾气、渐变天空或新光源。工具不能可靠保留其余属性时，用现成作品和一句短例继续问，不生成新图。代码中使用多少路径或滤镜本身不是计数依据，最终看实际可见差异是否仍只回答这一问。

两张完整的 1080×1920 版面草图、整页重排、多维改向或多个完整候选都算新版本；把它们缩小或拼在一张图里也不算局部。超出上述任一边界，就先走[访谈第 4 节](interview.md#4-问清楚的判据与确认)的需求理解报告与认可流程；用户在该节判据下明确改变流程并授权时按其范围执行，不能靠“临时对照”名义豁免。拒答后的假设也遵守此线，不能升级成完整研究稿。

生成辅助材料前先声明局部对象和单一维度，再把制作范围限制在该对象；完整标题、正文、全部信息区都被重新编排的图不是局部。若工具链从一个小对照开始扩展到整份稿件或多个整体变体，停下这条制作链，回到未解决的问题；不把最后新建文件叫“试验”就当作符合范围。真正获授权的新版制作使用执行分支，不受此局部范围限制。

前置声明不是一个等用户批准的独立回合。同一回合继续展示短例，或完成必要的受限制作、查看后，发出本问；不能只有“我会做局部对照”却既没有对照也没有问题。工具不成立时改用已观察作品能支撑的短问，不以等待用户说“继续”来补完本轮。

## 先分清表达含义与原因假设

用户的对象、行动和所处阶段不能被改写成你更熟悉的内容。“现在”与“这里”、“等候时怎么做”与“能办什么事”、“已经报名后”与“决定是否报名”可能指向不同结果。已有上下文能排除一种解释时直接沿用；仍有实质分歧才问用途，不索要只有某种解释才需要的详细资料。

观察到的特征、用户报告的感受、造成感受的原因是三件事。看见大字、亮色或密集信息可以成为提问依据，却不能直接说“你觉得累是因为信息太多”，再推荐删信息。没有观察证据时只说“可能”，不说“问题就是”；共同存在于多个失败版本的特征也只是候选原因。

例如，实际页面有醒目的促销数字和多个报名按钮，而用户说“不够高级”，不问“外观还是结构有问题”。可依据真实画面问：“这一版先看到醒目的报名数字和几个按钮。你更希望第一眼先明白活动有什么价值，还是先看到清楚的报名入口？也可能都不是。”只有当画面确有这些表现且两个答案会改变后续处理时才这样问；答案不能自动确认用户讨厌促销或要整体重做。

## 看似具体的回答里，仍有没说清的含义

不只判断整句话是否模糊。用户回答了问题、指出一个词、提出改法，仍可能留下会改变输出的歧义：例如“少点修饰”里的修饰指什么，“这里别这么满”里的这里是哪一部分，“把节奏放轻一点”是说声音、动作还是表达。它们是检查线索，不是关键词表，也不一律等同于要求减少内容。

先用当前原作、前一问和有效决定判断这个词在本次任务中的含义。如果已能确定，就继续，不要求用户再定义。仍有两个以上合理解释且会产生不同结果时，只保留该处为未决；明确部分不重问。选最影响下一步的一处，用原稿的短句、当前画面或可听片段把区别摆出来，问哪种表现更接近所指；允许都包括、都不是或说不清。不要泛问“请具体说明”，不要先宣布自己的释义，再让用户批准按它改全文。

把“说的是哪一处”和“那一处要变成什么”分别判断。回答若只指出“就是这圈光”，只解决对象，不代表要删除、减弱或换色；如果这些结果仍会导致不同改法，下一问继续针对同一处，只比较一个实际差别，例如“只看这圈光：维持现在的强度，还是淡一些？也可以都不是”。用原作或参考展示差别；确实看不出时，才做只改变这一项的临时局部对照。原本就明确说“去掉光晕，保留深色和状态标记”可直接执行；若它是访谈中的回答，不重问同一意思，而是记入详细需求理解报告，等用户核对认可后实施。

**虚构文案例子。** AI 问文章是否有 AI 味，用户答“你可能不该用很多的修饰”。原稿恰有“温暖而丰盛的交流会”和“让每个人都收获成长”。可问：“你说的‘修饰’，更接近‘温暖而丰盛’这种给事物加描述，还是‘让每个人都收获成长’这种替读者说效果很好？也可能两种都有，或者不是这两处。”这是借现有句子辨别含义，不是断言这两类一定造成 AI 味，也不要求用户先懂修辞术语；其他原作须换成其真实内容，不能虚构它也有这两句。

用户若答“不是不能写得美，是别替人说好”，只记录本次要减少无依据的效果评价，不扩大成删除全部形容词、比喻或缩短全文；仍未解决的范围继续问，关键含义和改向齐全后再按访谈流程确认。若答“我也说不清”，保留未知，换原文的另一处或事实相同、只改变这一处表达的短对照；不能把词换成“更自然”就宣布理解。

局部答案不是永久偏好。把已澄清的意思连同原句和适用范围保留在本任务，后续沿用；新的限定或否定只重开受影响分支。独立的明确小改如“删去首句的‘温暖而丰盛’，其他不动”直接执行；访谈中的具体回答则纳入当前报告，不再追问已清楚的含义，但也不跳过报告核对。

## 用户不知道怎样表达时

- 说不出风格名称或部位：从整体用途、第一眼感受或当前最想摆脱的印象起步，不要求指出精确像素。
- 想要“高级”但对示例无感：用途事实只有在确实未知且会改变判断时才问；用途已清楚，就比较当前作品或实际参考中可见的差别，不改问功能排序或使用习惯。
- 提供喜欢的参考：先看真实材料，再问哪种可见效果接近、哪些部分不希望照搬；与原要求冲突时只问那个取舍。
- 回答“都有一点”：允许多个目标并存，只有确实冲突才问优先级；不把不答或选择“都不是”当作默认偏好。
- 再次只说不满意：保留仍未回答的区别，接住新增线索后换更容易辨认的问法。没有新线索时改用当前作品或现成参照，不重复原题或换一组抽象形容词。
- 明说“脑子里没画面”“这些词我分不出来”或文字对照已无效：视觉任务展示能比较的实际画面，声音/动作任务提供可听或可播放材料；说明只比较哪一处。已整体否定的原稿不原样重摆要求重新认可；一组作品被全否时，可按[组级锚点](repeated-feedback.md#一组作品被整体否定时)只比较哪张最不差或使用用户已认可的外部参考。用户没有参考时由 Agent 寻找更有区分度的现成材料；确实无法展示时说明实际缺口，不能宣布方向明确。
- 拒答或明确不愿作专业判断：按[访谈第 4 节](interview.md#4-问清楚的判据与确认)先给同一问题的三个具体可见选项与“都不是”；仍拒答才提出受规模线限制的局部假设，不能当作委托或偏好。

完整方向确认前，不把两句短例包装成新稿或默认方案；喜欢某个局部也不等于同意照它重做全部。只为提出当前问题而做的单维临时局部对照按上文规模线处理；完整视觉/视频研究稿走已有报告流程或有效的明确改流程授权，征求意见和拒答都不是该授权。访谈帮助弄清目标，不证明实现方式已经可行；目标确定后由 Agent 选择实现，并通过真实成果检查。
