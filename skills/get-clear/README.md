# Get Clear｜问清楚再改

Easy Ask AI 的反馈澄清与返修 Skill。看到当前成果却只能说“AI味重”“不满意”“不好看”“不够高级”时，Agent 会结合作品调用 grilling，一次问一个关键问题，帮助你逐步说清期望。说“好点了，但还是不对”，同时建议参考案例或改法，也需要先弄清想要的体验。含糊访谈问清后，Agent 先在当前对话给出需求理解报告；你明确认可当前报告后，才按授权范围继续返修。

## 安装与调用

把完整 `get-clear` 文件夹安装到当前宿主实际确认的技能目录，保留入口、参考、示例、脚本、依赖锁定文件和许可证。目标已有同名目录时先核对本地修改并备份，不直接覆盖。产品、版本和部署方式不同，技能路径与宿主规则载体也可能不同；按[通用宿主安装、接入与撤销说明](references/host-integration.md)核实当前实例，不依赖固定厂商路径。

- 显式调用：在当前宿主提供的 Skill 列表中选择 `get-clear`，或使用该宿主实际显示的调用写法，再描述反馈。
- 隐式触发：对当前成果表达含糊的不满意，不需要点名。是否实际选择由宿主与模型决定；遇到漏选时先检查列表、调用策略和读技能记录。

希望日常返修先进入本流程时，可选择接入随包的[规则片段](assets/agents-snippet.md)。先在当前宿主调查有效载体与覆盖关系，按宿主实际格式和用户选定范围合并，保留原有内容，再按说明在新对话核验。这段规则让明确修改先读取执行说明、含糊反馈先读取访谈说明；复制 Skill 文件夹不会自动改用户或项目规则。其他宿主须根据实际配置和版本单独确认，不能沿用其他环境的加载结论。

准备交给安装 Agent 的启动提示词在[通用宿主接入说明](references/host-integration.md)中。把完整 Skill/套件的本机路径和期望范围一起发出。该起点可以在 Skill 尚未安装或被宿主发现前使用；仍须由能读取所给路径的 Agent 开始，Skill 不会在后台自行启动。

首次进入反馈访谈检查 `grilling` 与 `more-than-yes`，缺少时按 [依赖准备](references/dependencies.md) 在授权内补装。明确修改直接走执行分支，跳过访谈和依赖准备。辅助脚本需要 Python 3.10+，不自动安装系统运行时。只有本 Skill 不足以赋予宿主制作网页、生成视频等工具能力；实际返修使用现有领域工具。

## 你要回答什么

你不必先懂设计术语，也不必找一份完美参考。Agent 会带上当前作品的句子或可见表现问具体的感受、情境或对照，你可以回答“都不是”“都有一点”“说不清”。说不清时，它会用更容易辨认的短例继续问，不替你选方向，也不只要求你去找参考。每次回答都会改变下一问，已确定的内容不会反复询问。

访谈会弄清整体期望、需要保留和避免的内容、关键取舍与如何判断下一版。Agent 会在当前对话给出按任务充分展开的需求理解报告，写清目标和关键含义、拟改与保留、事实及范围边界、未决事项和检查方式，并区分你的决定、材料事实与 Agent 的建议或假设。你补充或纠正时，Agent 更新完整报告，只追问受影响的未决点；只有你明确认可当前报告后，才按获准范围执行和检查。明确小改直接做，你可随时停止或改变流程。

明确的小修改直接执行，不要求再次确认，也不能只说计划就结束。“其他文字和格式不动”还包括编码标记、混合换行和文件末尾空白。包内 [精确替换工具](scripts/edit_text.py) 支持 UTF-8 及带 BOM 的 UTF-16 文本，拒绝匹配数量错误和已检测到的文件变化，回读核验实际结果；不用于 Word、PDF 或未知编码。没有 Python 时按 [执行说明](references/execution.md) 使用宿主编辑工具并比较真实差异。

默认不生成交给别人的长 Prompt、不要求换窗口。只有你要求另一个对话执行时才切换到 Prompt Ready。多轮或中断需要时在现有任务记录中保存决定；无现有位置时使用 `.get-clear/<任务名>/requirements.md`。

完整流程见 [SKILL.md](SKILL.md)，提问方式见 [questioning.md](references/questioning.md)，演示见 [虚构网页返修](examples/landing-page.md) 与 [说不清时怎样继续](examples/unclear-copy.md)。纯文字访谈不能保证最终审美满意，最终仍要看实际作品。
