# 来源与归属

Get Clear 按维护者明确提出的“模糊否定后逐条追问，理解并确认后在原任务执行”要求重新设计；不是 Clear Feedback 的改名、复刻或运行入口。

维护期间核对了获准读取的本地反馈回合，用于区分实际观察与推测。私人记录、原文、项目身份和路径不进入本包；公开示例均为重新编写的虚构情境。

- [grilling](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336/skills/productivity/grilling)：决策树、依赖关系、回答后再深入与共同理解确认。Get Clear 将提问方式适配为一次一个主要问题，偏好选项不提供诱导性推荐。
- [more-than-yes](https://github.com/Ww-Cooooo/more-than-yes/tree/8e694886c9bbe610f04795f1221fb641f34f5e1f)：核对前提、证据、遗漏及实际结果。

两项运行依赖均单独安装并保留其 MIT 许可。固定版本和摘要见 [dependencies.lock.json](dependencies.lock.json)；许可声明见 [grilling](notices/grilling-MIT.txt) 与 [more-than-yes](notices/more-than-yes-MIT.txt)。本包复用 Easy Ask AI 内 Prompt Ready 的依赖安装辅助脚本，保留独立安装所需全部文件。

Skill Creator、Skill Improve 是制作与检查工具，不是使用者需要额外安装的运行依赖。方法归属与入口描述本身不构成效果保证。本包采用 [MIT](LICENSE)。
