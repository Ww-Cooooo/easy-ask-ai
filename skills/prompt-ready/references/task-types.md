# 按任务选择细化方向

只读取和应用当前任务相关的行。以下是开放的判断提示，不是问卷、能力白名单或固定产物要求。混合任务组合相关方向；未列出的领域从“使用情境—实际过程—结果—证据”推导。

| 任务 | 会改变结果的需求 | Agent 应调查的事实 | 执行说明要展开 | 有意义的验收 |
| --- | --- | --- | --- | --- |
| 软件、自动化、修改现有工程 | 用户动作、状态、输入输出、兼容、数据边界、运行方式 | 现有结构、入口、依赖、测试、已有改动 | 具体对象、接口、错误路径、实施顺序、运行和验证 | 典型与关键异常流程真实运行；保留已有功能 |
| 文档、课程、PPT | 读者起点、使用场合、学完/读完能做什么、版式与可编辑性 | 素材、模板、可用工具、现有章节、字体 | 内容论证、活动与案例、章节顺序、排版与导出 | 内容达成目标且成品可读；有排版要求时检查实际渲染 |
| 视频、音频、图像、设计 | 受众、表达意图、时长/尺寸、风格参照、声音和素材边界 | 原素材、许可依据、真实可用工具、输出能力 | 分段内容、画面/声音职责、制作与导出步骤 | 整体播放/观看可理解；连续性、节奏和导出规格符合需求 |
| 调研、比较、决策支持 | 要做的决定、对象范围、时效、证据强度、评价维度 | 原始来源、时间、样本与信息缺口 | 检索路线、核验、比较口径、分析及不确定性 | 来源支持结论；分清事实、推断、未知；回答原始决定 |
| 数据、表格、分析 | 统计单位、口径、缺失/重复处理、更新方式、读者用途 | 字段、样本、公式、来源、工具 | 清洗规则、计算、核对、呈现和复现 | 抽样复算正确，口径一致；不只检查图表是否生成 |
| 业务流程、活动、运营 | 参与者、触发条件、时序、责任、渠道、资源与授权 | 当前流程、资料、平台限制、真实依赖 | 各步骤角色、输入输出、例外、执行和反馈 | 从具体场景走通，责任明确，未授权外发仍需授权 |
| Skill、提示词、工作流 | 触发边界、未来使用者、宿主、正常输入、完成标准 | 现有包、资源、调用条件与来源 | 方法、判断依据、必要示例、依赖与验证 | 新执行者仅凭正常材料能完成代表任务；静态与行为证据分开 |

避免跨领域误套：视频的“质量检查”不能只写单元测试；软件的“高级感”不能只提供形容词；研究的“完成”不能只按字数计算。

无法观察成品质量时，在 Prompt 中说明需要什么工具或用户提供什么结果才能验收。不要用方便的替代检查冒充缺失的核心检验。
